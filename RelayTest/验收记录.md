# iDUI 继电器模块测试验收记录

**验收日期** 2026-11-25（北京时间）

**验收结论** 通过。用户确认 GPIO32 和 GPIO33 两路继电器的独立吸合与断开测试通过。

## 测试环境

- 测试对象为 iDUI PCB 上由 ESP32 的 GPIO32、GPIO33 控制的两路继电器。高电平吸合，低电平断开。
- 目标芯片为 ESP32-D0WD-V3（v3.1），板载 Flash 为 4 MB。
- 通过 CH340 下载器连接至 `COM8`。烧录前备份了原有 Flash，测试固件烧录后通过写入校验。串口测试波特率为 `115200`。
- [继电器测试固件](./RelayTest.ino)

## 测试步骤

1. 启动测试固件，发送 `?` 检查两路 GPIO 均为低电平。
2. 发送 `1`，将 GPIO32 拉高约 5 秒后拉低。回读确认 GPIO33 在测试期间保持低电平。
3. 间隔约 4 秒后发送 `2`，将 GPIO33 拉高约 5 秒后拉低。回读确认 GPIO32 在测试期间保持低电平。
4. 再次发送 `?`，确认两路回到低电平。

## 测试结果

| 测试通道 | 吸合阶段回读（GPIO32 / GPIO33） | 断开后回读（GPIO32 / GPIO33） | 串口结果 |
| --- | --- | --- | --- |
| GPIO32 | 1 / 0 | 0 / 0 | 通过 |
| GPIO33 | 0 / 1 | 0 / 0 | 通过 |
