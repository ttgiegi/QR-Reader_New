# iDUI 焊接版屏幕功能测试验收记录

**验收日期** 2026-11-25（北京时间）

**验收结论** 通过。用户观察实物后确认，全屏颜色、竖色条和背光开关均符合预期。

## 测试环境

- 屏幕为焊接版 T200H7-H12-01，控制器为 ST7789V2，分辨率为 240 × 320。
- 使用 ESP32-D0WD-V3（v3.1），通过 CH340 下载器在 `COM8` 烧录，写入校验通过。串口日志波特率为 `115200`。
- 固件采用焊接版 Arduino 参考代码的初始化参数，设置为 SPI Mode 0、1 MHz、RGB666。
- [屏幕测试固件](./ScreenTest.ino) · [焊接版 Arduino 参考代码](../单屏-焊接12P-T200H7-H12-01/参考代码/参考代码/Arduino/20TFT7PINspi/20TFT7PINspi.ino)

## 引脚核对

| 屏幕信号 | ESP32 引脚 | 用途 |
| --- | --- | --- |
| SDA | GPIO23 | SPI MOSI |
| SCLK | GPIO18 | SPI 时钟 |
| CS | GPIO5 | SPI 片选 |
| DCX | GPIO2 | 数据与命令选择 |
| RES | GPIO15 | 屏幕复位 |
| BL | GPIO13 | 高电平开启背光 |

六个引脚与硬件接线说明和测试固件一致。

## 实物验收

| 测试项 | 预期表现 | 结果 |
| --- | --- | --- |
| 全屏纯色 | 红、绿、蓝、白、黑依次显示，每色约 3 秒 | 通过 |
| 竖色条 | 红、绿、蓝、白、黑从左至右铺满屏幕 | 通过 |
| 背光开关 | 色条显示约 6 秒后背光关闭约 2 秒，再开启并恢复显示原色条 | 通过 |
